# CI and releases

The workflow follows lmnum and the finished lmspace example, including LF checkout enforcement for SDK hashes, schema bytes and dependency pins. Five platform jobs cover Linux x64/arm64, macOS x64/arm64 and Windows x64. All install `@lmctl-ai/lmctl@0.2.369`, set `GITHUB_TOKEN` and `LMBIO_TEST_NETWORK`, run test.sh and publish a platform artifact.

A v* tag rebuilds all five platforms. The release job depends on their success, checks the binary version against the tag, and publishes five binaries plus LICENSE and THIRD_PARTY_NOTICES. Only the release job has contents-write permission. Docs-only pushes do not trigger the matrix.
