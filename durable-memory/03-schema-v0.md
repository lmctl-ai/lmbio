# Schema and supported SBML semantics

The generated schema has context `bio: Bio`, with 5 Bio methods, 19 Model methods and 13 Result methods (0.2.0). `scripts/gen-schema.py` reads literal registrations from cpp/main.cpp with whitespace-independent patterns. test.sh compares registry signatures to the compiler and checks byte-identical embedded schema. The SDK header and its hash are pinned in sdk.lock.

Host objects have stable heap addresses and live until process exit, with a 100000-object limit per arena. A Model owns compartment/species/reaction/rule data; const simulation calls leave initial data unchanged. set/get address initial species, parameter or compartment-size values (compartments since 0.2.0; a size must stay positive). Time symbols `t` and `time` are reserved identifiers; expressions use t and results use time. All global IDs are unique SBML-style identifiers. Local kinetic parameters shadow globals only within their reaction.

Species values are concentrations unless SBML hasOnlySubstanceUnits is true. Reaction extents are amounts/time; concentration derivatives divide by the fixed compartment volume. InitialAmount and initialConcentration are converted into the proper symbol value. Boundary/constant species stay fixed through reactions; nonconstant boundary species can be governed by an explicit rate rule. Rules cannot conflict with nonboundary reaction-controlled species. Assignment rules are topologically ordered and recomputed at initial/output times. Cycles, unknown references, nonfinite rates and malformed equations fail clearly.

Deterministic stoichiometry may be fractional and nonnegative. SSA requires unit volumes and exact nonnegative integer counts/stoichiometry; propensities are user expressions in counts. Unavailable-reactant channels have zero propensity. Boundary/constant counts remain fixed. Forward/reverse channels are separate; explicit time-dependent propensities and rules are rejected. SSA samples a right-continuous firing process. Its seed path is independent of output grid resolution.

SBML L3V1/V2 core namespaces (default or prefixed) are checked. Supported data: fixed compartments, species flags and initialization, global/local parameters, kineticLaw MathML, assignment/rate rules. metaid and sboTerm attributes are accepted and ignored. A compartment without size, or a species/parameter without an initial value that no assignment rule defines, is an error (Level 3 has no defaults; no value is guessed). tests/fixtures/semantics.xml checks volume scaling, hasOnlySubstanceUnits, stoichiometry, boundary/constant species, rate rules, reversible net laws and local-parameter shadowing against closed forms, before and after a round trip. Units are metadata only: no unit conversion or dimensional validation is performed, and export does not preserve unit annotations. Unsupported packages, events, delays, initial assignments, algebraic rules, function definitions, dynamic compartments/stoichiometry and conversion factors are errors. This is a bounded subset, not a full SBML validation/conformance implementation.

Supported MathML includes cn (real/integer/e-notation/rational), ci, time csymbol, pi/exponentiale, arithmetic plus/minus/times/divide/power, roots with degree, exponential/logarithmic functions, standard trigonometric functions, abs/floor/ceiling. MathML log defaults to base 10; expression log/ln are natural logarithms. Piecewise, logical/comparison expressions and user functions are not supported. Expression functions outside the writer subset produce an explicit export error instead of invalid MathML. Scientific notation is emitted using cn type=e-notation and sep.

save_sbml writes L3V2 with precision-17 values, valid mathematical operators and flags, scoped local parameters and collision-free reverse reaction IDs. Reversible builder rates become separate irreversible reaction elements with equivalent net dynamics. Exported rule-target parameters are marked nonconstant. XML is escaped by pugixml.

Result matrices contain time, species in creation order and parameters in sorted identifier order. rows()/cols()/get()/column() expose matrix access; value(id,row)/final(id)/max(id)/time_of_max(id) provide named access. CSV includes a header and 17-digit values. Rows are zero-based. The host supports only standard queries and --dsl; --dry-run validates bytecode without execution. Usage exits 2; load/run errors exit 3 with SDK source diagnostics.

## Additions in 0.2.0

- `mass_action(id, equation, k)` builds the deterministic extent `(k)*V*A^a*B^b` (V = compartment of the first reactant, or of the first product for a source) so a concentration changes by `k*[A]^a*[B]^b` per stoichiometric unit, and stores the SSA propensity `(k)*A*(A-1)*...` (falling factorials, no 1/a!) whose large-count drift equals the ODE with the same k in unit volume. `k` is an expression string. Non-integer coefficients keep only the ODE law. `mass_action_reversible(id, equation, kf, kr)` adds the reverse law on the products. The SSA propensities live in `Reaction::ssa_rate/ssa_reverse`; `ssa()` swaps them in, ODE, steady state, sensitivity and SBML export use the ODE law (a reloaded SBML model therefore uses the ODE law for SSA too).
- `set_state(result)` copies the last row of a result into species initial values and parameter values (round-off below -1e-12 x max is clamped to 0, real negatives are errors). With `Result.append` it makes repeated dosing and other discontinuities scriptable without SBML events.
- `Result.append(next)` requires identical columns and a next start time not before this end time; when the first row of `next` equals the last row exactly it is dropped, otherwise both rows are kept so a jump stays a vertical step and `integral` stays exact.
- `Result.min(id)`, `Result.integral(id)` (trapezoid over the sampled rows) and `Result.crossing(id, level)` (first sample interval that reaches the level from either side, linearly interpolated; an error if the level is never reached).
Tests: tests/mass_action.lms (dimerization closed form in volume 2, binding equilibrium, falling-factorial SSA with 1 and 2 molecules, birth-death time average, compartment get/set), tests/dosing.lms (ten boluses vs the geometric series, crossing at ln2/k, minimum, AUC mass balance, append without a jump), and four new error cases in test.sh.
